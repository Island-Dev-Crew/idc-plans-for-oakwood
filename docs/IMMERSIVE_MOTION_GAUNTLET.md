## Why this pass exists

The first release delivered editorial quality, institutional credibility, and evidence clarity, but its motion language stopped at restrained entrances and state changes. This pass treats Iron Canvas as a quality framework—not a visual ceiling—and adds motion only where it explains how Oakwood evidence becomes a commissioned production system.

## Independent gauntlet findings

Three critic seats were dispatched against the canonical site and working source:

1. **Motion director:** canonical site was kinetically inert; recommended `Trace → Commission → Verify`, actual room/conduit/bench language, a commissioned lab route, no generic particles/orbits, no agency cursor, and no perpetual loops.
2. **Visual satisfaction critic:** canonical site failed Tier 3 at **6.5/10** because it lacked a living map, scroll-tied narrative, memorable interaction, and authored mobile equivalent.
3. **Performance/accessibility critic:** timed out. This is recorded as **no reviewer verdict**, not a pass. Repeatable coded browser assertions and Lighthouse results provide the technical evidence instead.

The first immersive prototype was also rejected after the motion director inspected its local source: its custom cursor and orbiting-node constellation were generic AI decoration. The provisional **8.6/10** claim was withdrawn.

## Refactoring delivered after critic reconciliation

- Replaced the generic `ProofConstellation` with an Oakwood-specific `ProofTrace` room-plan canvas.
- The trace connects documented **Room 409 → power/data → reusable assets → studio → local inference → verification → evidence vault → opportunity**.
- Motion thesis changed to **Trace → Commission → Verify**.
- Replaced circles/orbits with cinderblock-grid geometry, rectangular system blocks, and orthogonal conduit paths.
- Removed the custom motion cursor completely.
- Removed perpetual hero sweep, core pulse, signal loop, and perpetual canvas RAF.
- Canvas renders only while interpolating toward a new scroll state, then stops.
- Added a stateful lab workload route: selected source → local inference → proof wall → evidence vault.
- Added `aria-pressed` to every lab control and a live route ledger readout.
- Moved the route readout out of the diagram after mobile overlap was detected.
- Replaced the clipped horizontal mobile trace with a dedicated vertical commissioning sequence.
- Reduced mobile hero type to approximately 51px with gentler tracking.
- Retained scroll-triggered score bars, chapter arrivals, staged ledger entrance, and meaningful hover/focus feedback.
- Preserved static, compact reduced-motion behavior.

## Coded assertions

`qa_motion.py` now fails if any of the following regress:

- HTTP or console health.
- Desktop/mobile overflow.
- Three distinct scroll states.
- Canvas dimensions.
- Visible-by-default content.
- Frame budget.
- Canvas fails to settle.
- Custom cursor returns.
- Trace/Commission/Verify language disappears.
- Lab buttons lose `aria-pressed`.
- Reduced-motion canvas moves or CSS animations remain.
- Reduced-motion section is no longer compact/static.

`qa_10x.py` additionally fails if:

- The AAMU / Oakwood / IDC / proposed-opening evidence lanes disappear or blur together.
- The 522-page bulletin scan or five verified foundation tabs regress.
- Curriculum inference, proposed target, unknown, official-marketing, or catalog-conflict labels are absent.
- Any rendered claim tag lacks an explicit typed `data-claim-kind`.
- The canonical 16-source manifest loses required fields, unique IDs, or parity with the rendered ledger.
- Foundation tabs lose selection behavior.
- A fixed header covers anchor targets.
- Horizontal overflow appears at desktop or mobile.
- External Google Font requests return.
- `llms.txt` machine provenance is missing.
- Reduced-motion exposes the bulletin scanner.
